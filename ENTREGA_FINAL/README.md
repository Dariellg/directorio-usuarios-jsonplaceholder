# Entrega final — Directorio JSONPlaceholder

Esta carpeta contiene los artefactos verificables de la sesión:

- `REPORTE_VALIDACION.md`: resultados reales, separados por aprobados, fallidos y no ejecutados.
- `evidencias/`: capturas obtenidas mediante ADB. Las imágenes que contienen un diálogo de `System UI` están marcadas como inválidas.
- `app-debug.apk`: APK debug generado por Gradle.

El código fuente está en la raíz del proyecto. No se incluye un enlace GitHub porque el repositorio no ha sido publicado ni se recibió autorización para hacerlo.

El documento Word del profesor está disponible en la raíz como [Directorio_Usuarios_JSONPlaceholder_WORD.docx](../Directorio_Usuarios_JSONPlaceholder_WORD.docx). No se renombra como documento final para evitar presentar una plantilla no auditada como entrega definitiva.
