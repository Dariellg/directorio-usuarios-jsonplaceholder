1. Resumen

Aplicación Android nativa en Kotlin con Jetpack Compose, Retrofit, Room y arquitectura MVVM. Consulta usuarios y publicaciones desde JSONPlaceholder, muestra el detalle y persiste favoritos localmente.

3. Retrofit

interface UsersApi { @GET("users") suspend fun getUsers(): Response<List<User>> @GET("posts") suspend fun getPosts(@Query("userId") userId: Int): Response<List<Post>> } Base URL: https://jsonplaceholder.typicode.com/

4. Room

@Entity(tableName = "favorites") data class FavoriteEntity(@PrimaryKey val id: Int, val name: String, val email: String, val company: String, ...) @Dao interface FavoriteDao { @Query("SELECT * FROM favorites ORDER BY name") fun observeAll(): Flow<List<FavoriteEntity>> @Upsert suspend fun upsert(favorite: FavoriteEntity) @Query("DELETE FROM favorites WHERE id = :id") suspend fun delete(id: Int) }

5. Ciclo de vida y estados

El ViewModel inicia observación de favoritos y carga de usuarios dentro de viewModelScope. Compose recoge el StateFlow mediante collectAsStateWithLifecycle. La pantalla de detalle carga publicaciones al cambiar el usuario. Se implementan Loading, Success y Error; IOException muestra ausencia de conexión y permite reintentar.

8. Conclusiones

La solución separa UI, ViewModel, repositorio, API y persistencia. Retrofit convierte JSON a modelos Kotlin y Room conserva favoritos localmente. Compilación, instalación, consulta remota, navegación y publicaciones fueron verificadas. La validación offline requiere un AVD estable o dispositivo físico.
